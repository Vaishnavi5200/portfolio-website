FEATURED PRODUCT

CareerOS Active Development

From placement tracker to a focused career operating system for students.

Open Live Product Source Code

CareerOS is my evolving product vision for helping students manage applications, DSA preparation, interview readiness and long-term career progress from one unified dashboard. PlacementTrack Pro is the current working foundation of CareerOS.

Problem

Students manage applications, DSA progress, follow-ups and preparation across disconnected spreadsheets, notes and platforms. Nothing is connected, so nothing is trackable.

Solution

CareerOS brings those workflows together into one structured system — one login, one dashboard, everything connected.

Currently Implemented

  • Secure JWT authentication
  • Job and internship application tracking
  • Follow-up management
  • Placement dashboard overview
  • DSA problem tracking
  • Topic and difficulty management
  • Revision tracking per problem
  • Daily solving streak
  • Search and filtering
  • Responsive interface
  • MongoDB data persistence
  • Full CRUD workflows

Product Evolution

  1. 01 Placement tracking prototype
  2. 02 Full-stack MERN application
  3. 03 Authentication and persistent user data
  4. 04 DSA Tracker integration
  5. 05 CareerOS product expansion Now
